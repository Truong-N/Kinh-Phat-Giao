What Are Some Common ARIA States Used on Custom Control Elements? Một số trạng thái ARIA phổ biến được sử dụng trên các phần tử điều khiển tùy chỉnh là gì?

Semantic form control elements like input, select, textarea, button, and fieldset have built-in states that are conveyed to assistive technologies. Các phần tử điều khiển biểu mẫu ngữ nghĩa như input, select, textarea, button và fieldset có các trạng thái tích hợp được truyền đạt đến các công nghệ hỗ trợ.

For example, you could use the disabled attribute to disable a button or the checked attribute to indicate that a checkbox is checked. Ví dụ, bạn có thể sử dụng thuộc tính disabled để vô hiệu hóa một nút hoặc thuộc tính checked để cho biết hộp kiểm đã được chọn.

But if you are creating a custom control element, you need to use ARIA attributes to convey the state of the control to assistive technologies. Nhưng nếu bạn đang tạo một phần tử điều khiển tùy chỉnh, bạn cần sử dụng các thuộc tính ARIA để truyền đạt trạng thái của điều khiển đến các công nghệ hỗ trợ.

In this lesson, we will discuss a few common ARIA states that you can use on custom control elements. Trong bài học này, chúng ta sẽ thảo luận về một vài trạng thái ARIA phổ biến mà bạn có thể sử dụng trên các phần tử điều khiển tùy chỉnh.

The first ARIA state we will discuss is aria-selected. Trạng thái ARIA đầu tiên mà chúng ta sẽ thảo luận là aria-selected. This state is used to indicate that an element is selected. Trạng thái này được sử dụng để cho biết một phần tử đã được chọn. You can use this state on custom controls like a tabbed interface, a listbox, or a grid. Bạn có thể sử dụng trạng thái này trên các điều khiển tùy chỉnh như giao diện tab, hộp danh sách hoặc lưới.

  const tabs = Array.from(tablist.querySelectorAll('[role="tab"]'));
  const index = tabs.indexOf(activeTab);

  let newIndex = index;
  if (event.key === "ArrowRight") newIndex = (index + 1) % tabs.length;
  if (event.key === "ArrowLeft") newIndex = (index - 1 + tabs.length) % tabs.length;

Native elements typically have better support and built-in accessibility features. Các phần tử gốc thường có khả năng hỗ trợ tốt hơn và các tính năng trợ năng tích hợp sẵn.

However, if you must create custom controls, using ARIA attributes is essential to convey the state of these controls to assistive technologies effectively. Tuy nhiên, nếu bạn phải tạo các điều khiển tùy chỉnh, việc sử dụng thuộc tính ARIA là điều cần thiết để truyền đạt trạng thái của các điều khiển này cho các công nghệ hỗ trợ một cách hiệu quả.

As always, test your work to ensure that ARIA attributes are applied correctly and that the custom control functions in a way that is both accessible and user-friendly. Như mọi khi, hãy kiểm tra công việc của bạn để đảm bảo rằng các thuộc tính ARIA được áp dụng chính xác và điều khiển tùy chỉnh hoạt động theo cách vừa dễ truy cập vừa thân thiện với người dùng.
