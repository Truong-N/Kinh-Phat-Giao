What Is the aria-controls Attribute, and How Does It Work? Thuộc tính aria-controls là gì và hoạt động như thế nào?

The aria-controls attribute is used to create a programmatic relationship between an element that controls the presence of another element on the page, and the element it controls. Thuộc tính aria-controls được sử dụng để tạo mối quan hệ lập trình giữa một phần tử điều khiển sự hiện diện của một phần tử khác trên trang và phần tử mà nó điều khiển. This relationship can help screen reader users better understand how the control works. Mối quan hệ này có thể giúp người dùng trình đọc màn hình hiểu rõ hơn cách hoạt động của điều khiển. Common uses include a set of tabs that control the visibility of different sections of content, or a button that toggles the visibility of a menu. Các trường hợp sử dụng phổ biến bao gồm một tập hợp các tab điều khiển khả năng hiển thị của các phần nội dung khác nhau hoặc một nút chuyển đổi khả năng hiển thị của menu.

Each button represents a tab and has a role attribute set to tab. Mỗi nút đại diện cho một tab và có thuộc tính role được đặt thành tab. In most tabbed interfaces, the first tab panel is visible by default, so the first tab button has an aria-selected attribute set to true to indicate that its associated section of content is currently visible. Trong hầu hết các giao diện dạng tab, bảng tab đầu tiên được hiển thị theo mặc định, vì vậy nút tab đầu tiên có thuộc tính aria-selected được đặt thành true để chỉ ra rằng phần nội dung liên quan của nó hiện đang hiển thị. The aria-controls attribute is used to associate each button with the section of content that it controls. Thuộc tính aria-controls được sử dụng để liên kết mỗi nút với phần nội dung mà nó điều khiển.

const tabs = document.querySelectorAll('[role="tab"]');
const tabList = document.querySelector('[role="tablist"]');

tabs.forEach(tab => {
  tab.addEventListener('click', () => {
    activateTab(tab);
  });

  tab.addEventListener('keydown', (e) => {
    const key = e.key;
    const currentIndex = Array.from(tabs).indexOf(tab);
    let newIndex = null;

    if (key === 'ArrowRight') {
      newIndex = (currentIndex + 1) % tabs.length;
    } else if (key === 'ArrowLeft') {
      newIndex = (currentIndex - 1 + tabs.length) % tabs.length;
    } else if (key === 'Home') {
      newIndex = 0;
    } else if (key === 'End') {
      newIndex = tabs.length - 1;
    }

    if (newIndex !== null) {
      tabs[newIndex].focus();
      activateTab(tabs[newIndex]);
    }
  });
});

function activateTab(tab) {
  const tabPanels = document.querySelectorAll('[role="tabpanel"]');

  tabs.forEach(t => {
    t.setAttribute('aria-selected', 'false');
    t.setAttribute('tabindex', '-1');
  });

  tabPanels.forEach(panel => panel.hidden = true);

  tab.setAttribute('aria-selected', 'true');
  tab.removeAttribute('tabindex');

  const panelId = tab.getAttribute('aria-controls');
  const panel = document.getElementById(panelId);
  panel.hidden = false;
  tab.focus();
}

Each section of content has a role attribute set to tabpanel and an aria-labelledby attribute that points to the corresponding tab to give the panel an accessible name. Mỗi phần nội dung có thuộc tính role được đặt thành tabpanel và thuộc tính aria-labelledby trỏ đến tab tương ứng để đặt tên dễ truy cập cho bảng điều khiển. The hidden attribute is used to hide the sections of content that are not currently selected. Thuộc tính hidden được sử dụng để ẩn các phần nội dung hiện không được chọn. Each section ID matches the value of the aria-controls attribute on the corresponding button. Mỗi ID phần khớp với giá trị của thuộc tính aria-controls trên nút tương ứng. The section1 ID matches the aria-controls attribute on the first button, section2 matches the aria-controls attribute on the second button, and section3 matches the aria-controls attribute on the third button. ID phần 1 khớp với thuộc tính aria-controls trên nút đầu tiên, phần 2 khớp với thuộc tính aria-controls trên nút thứ hai và phần 3 khớp với thuộc tính aria-controls trên nút thứ ba. This is how the association between the tabs and their sections of content is established. Đây là cách thiết lập mối liên hệ giữa các tab và các phần nội dung của chúng.

To switch between the different sections you will need to use JavaScript to update the hidden attribute on the section and the aria-selected attribute on the button based on which section is currently visible. Để chuyển đổi giữa các phần khác nhau, bạn cần sử dụng JavaScript để cập nhật thuộc tính hidden trên phần và thuộc tính aria-selected trên nút dựa trên phần nào hiện đang hiển thị. Only one section can be visible at a time and it should not have the hidden attribute and aria-selected should be set to true on its button. Chỉ một phần có thể hiển thị tại một thời điểm và phần đó không nên có thuộc tính hidden và thuộc tính aria-selected nên được đặt thành true trên nút của nó. The remaining hidden sections should all have the hidden attribute and aria-selected should be set to false on their buttons. Các phần ẩn còn lại đều nên có thuộc tính hidden và thuộc tính aria-selected nên được đặt thành false trên các nút của chúng.

Tabs are a common use case for the aria-controls attribute, but it can be used in other scenarios where one element controls the visibility or behavior of another element. Tab là một trường hợp sử dụng phổ biến cho thuộc tính aria-controls, nhưng nó có thể được sử dụng trong các trường hợp khác, nơi một phần tử kiểm soát khả năng hiển thị hoặc hành vi của một phần tử khác. Other examples include accordions, dropdown menus, and modals. Các ví dụ khác bao gồm accordion, menu thả xuống và modal.

The next time you design a user interface that involves controlling the visibility of elements, consider using the aria-controls attribute to establish the relationship between the controlling element and the controlled element. Lần tới khi bạn thiết kế giao diện người dùng liên quan đến việc kiểm soát khả năng hiển thị của các phần tử, hãy cân nhắc sử dụng thuộc tính aria-controls để thiết lập mối quan hệ giữa phần tử điều khiển và phần tử được điều khiển.
